# Agent tools

Browser AI agents drive the editor through typed tools instead of clicks. The same eleven tools reach agents by two routes: WebMCP and Chrome DevTools MCP.

## Sub-features

`get_editor_state`, `list_themes`, `set_code`, `add_tab`, `select_tab`, `read_tab`, `duplicate_tab`, `apply_theme`, `set_controls`, `set_animate_mode` and `export_image`. Each description follows one pattern: what it does, when to use it rather than its neighbour, a one-line JSON example and what it returns; every parameter has its own description. `get_editor_state` lists the tabs as `{index, name, language, active}` and the settings as `{name, value, ...}`. Setting names have no dots (`frame_padding`, `editor_line_number_start`), because small models split dotted keys into nested objects, and `set_controls` takes them as its top-level arguments: `{"frame_padding": "64"}`. `set_code` and `add_tab` return the tab they wrote with its editor `id`, which their rows use for a Format button (`FormatTabButton.tsx`, `format-tab.ts`). `set_animate_mode {open}` shows or hides the Animate panel. `duplicate_tab` copies a tab (the active one by default) in the page, code and language included, as "index copy.tsx", and selects the copy. `read_tab` returns a tab's `{tab, code}` without switching to it, and the active tab when given neither name nor index. `get_editor_state` and `read_tab` carry `untrustedContentHint`, since their code is text the user did not write. `add_tab` makes the new tab active and refuses a seventh tab; `select_tab` takes a 0-based `index` or a `name` and lists the tabs when neither matches. Invalid input returns `{ok: false, error}` and changes nothing; `set_controls` applies its valid entries and lists the rest under `errors`. Mutating tools refuse a read-only or loading snippet. `export_image` waits for the real outcome; with likely secrets in the code it exports nothing and opens the review dialog for the user. A clipboard export reports `started`, since the copy finishes in the background.

The person watching sees each call in a floating card at the bottom left, above the What's new Nudge: the localized title, the raw tool name, a short summary of the arguments (never the code, only its line count), and a spinner, check or cross. A failed call shows its error. `withActivity` in `activity.ts` records the calls for the WebMCP, DevTools and Local AI routes; `ToolActivity.tsx` draws them.

## How to get to it (agent POV)

**WebMCP.** On `/`, the page registers the tools with `document.modelContext` (or `navigator.modelContext` in older Chrome previews) while the editor is mounted. Without that API nothing is registered. An agent that supports WebMCP lists and calls them by name.

**Chrome DevTools MCP.** Start the server with third-party tools enabled, for example `npx chrome-devtools-mcp@latest --categoryExperimentalThirdParty=true`. Open the editor in the controlled Chrome. `list_3p_developer_tools` returns the `CodeImage` group with each tool's input schema. `execute_3p_developer_tool` runs one for that page; its `params` argument is JSON text. The page answers the `devtoolstooldiscovery` window event and installs no window global.

## Driving it with Playwright

`VERIFY_AUDIT=1 VERIFY_CASES=agent-tools node .agents/skills/verify-codeimage/scripts/verify.mjs`

The case runs in a fresh Inspector context whose init script installs a recording `document.modelContext`. It waits for all eleven tools, checks that only `get_editor_state` and `read_tab` carry `untrustedContentHint` and that no schema has a dotted or `values`-wrapped argument, then calls their `execute` as an agent would. It asserts that `set_code` with `Python` changes the CodeMirror text and the language picker, and that an unknown language writes no code. `apply_theme` must select Dracula in the theme list, and an unknown theme must return suggestions and keep it. `set_controls` must change the live frame's computed padding, and an out-of-range `frame_opacity` must apply nothing. It downloads PNGs at 1x and 2x through `export_image` and checks the 2x size is twice the 1x size. It also checks that an invalid scale is rejected. Then it dispatches a synthetic `devtoolstooldiscovery` event with a `respondWith` spy and applies Night Owl through the received group. Last, `add_tab` with code, `Python` and `main.py` must show the new code in CodeMirror; an unknown language adds no tab; `select_tab` by index and by name (ignoring case) must switch the CodeMirror text; an unknown name lists the tabs; `read_tab` by name returns the other tab's code while CodeMirror and the active tab stay put, `read_tab` with no arguments returns the active tab, and an unknown name fails; `duplicate_tab {}` copies the active tab as `main copy.py` with its code; `set_animate_mode` turns Animate on and off as `get_editor_state` reads back; and the seventh `add_tab` must fail with the limit. Then it checks the activity card. After the earlier calls' card has hidden, it starts a PNG export and sees its row `running`, then runs `set_code`, `apply_theme`, `set_controls`, a failing `apply_theme` and `list_themes`. The calls from before the card hid must come back above them, and the last six rows must show each raw tool name, status, summary (`PNG · 2x · download`, `TypeScript · 2 lines`, `padding N`) and the failure's error, with `list_themes` marked read-only. The code text must never appear in the card, and the chip must read `WebMCP`. Hovering keeps the card open past 5 s, and it hides about 10 s after the pointer leaves. Hiding keeps the calls: the next call brings the card back with them, and only Dismiss clears them. At 390px a DevTools call shows the card 16px from each side with a `DevTools MCP` chip and the earlier calls still listed, and Dismiss removes it. Last, with `?whatsNew=nudge`, the card must sit above the Nudge. Evidence lands in `agent-1x.png`, `agent-2x.png`, `agent-activity.png`, `agent-activity-phone.png`, `agent-activity-nudge.png` and `agent-tools-trace.zip`.

Source: `pages/UnifiedEditor/agent-tools/` (`tools.ts` is the registry, `adapters.ts` the WebMCP and DevTools adapters, `values.ts` the pure parsing with its unit tests, `activity.ts` the call log and summaries with their unit tests, `ToolActivity.tsx` the card) and `shell/export.tsx` for `ExportOutcome`.

## Gotchas

The browser case sends a mixed `set_controls` request with a padding choice, an opacity value, a line-number toggle and an unknown property. It checks the partial result, reads the committed values back, checks the rendered padding, and verifies that an out-of-range opacity leaves the previous value intact. It also checks that hiding the frame prevents an opacity change in the same request, and that showing the frame again makes the change available immediately.

The recording `modelContext` stands in for a real agent. It proves registration, schemas and effects, not a vendor's agent UI. Real WebMCP agents and Chrome DevTools MCP need a manual run. Choice schemas carry an `enum` of option values fixed at registration, except `editor_theme` and `editor_formatter`, whose options change while the page runs. Their live values come from `get_editor_state`.
