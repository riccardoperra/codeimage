# Animate

Play one tab morphing into the next, and edit timing with a fitted desktop timeline or a phone step list saved with the document.

## Sub-features

Animate toggle and island in Inspector, Dock and Studio; steps seeded from the tabs on the first open; play, pause, stop and scrub; hold and transition segments with desktop drag resize, arrow nudge and a typed duration; phone overview scrubbing, step rows and a modal bottom sheet; easing presets and a custom curve per transition, Apply to all; header mode (Current tab, Title only with a title, All tabs); Steps menu (Add to animation, Duplicate as next step, Move earlier, Move later, Remove step); preview pill that returns to the code of step N; persistence in IndexedDB for a guest.

## How to get to it (user POV)

Guest `/`, with two tabs or more to have something to play. Press Animate in the frame actions under the canvas (Inspector, Studio, Dock desktop), the play icon after More in Dock's phone bar, or the play icon in Studio's phone actions. The command menu also lists Animate, Play or pause the animation and one command per header mode. The island docks under the canvas. Editable saved projects use the same unified editor; read-only pages hide editing controls.

## Driving it with Playwright

Audit `animate` selects the Editor window (named Add tab), writes two tabs, clicks `[data-animate-toggle]` and waits for `[data-animate-panel]` (region `Animation`) with `aria-pressed="true"` on the toggle. Segments are `[data-animation-segment]` with `data-kind="hold"` or `"transition"`, `data-step-id`, `aria-valuenow` in ms, and `data-selected` / `data-current` as present-or-absent attributes. It clicks button `Play animation`, waits for `[data-animation-stage]:visible` and `[data-preview-pill]`, waits for `[data-animation-time]` to leave `0.00 s`, then clicks the pill and asserts the stage is gone and the editor holds focus. It drags the first hold's `[data-segment-resize]` with real mouse moves, asserts mid-drag that the segment's `aria-valuenow` moved to a multiple of 100 and the fitted axis grew by the same duration, releases, then reloads, reopens Animate and reads the same value back.

Other proven handles: slider `Playhead` (click or drag to scrub, release keeps the position); buttons `Pause animation`, `Stop and edit the code`, `Close animation`, `Steps`, `Apply to all`; the header select is the button named `Header …` with options `Current tab`, `Title only`, `All tabs`, and textbox `Title` (the header field follows the current strip or list mode); `#animationDuration-input` for the selected segment; `[data-easing-trigger]` opens dialog `Easing` with tabs Smooth, Snappy, Strong, Linear, Custom, image `Easing curve`, `[data-easing-dot]` while the playhead is inside that transition, and button `Play transition`. Each scene is a `[data-animation-scene]`; only the shown one is not `display: none`, and its header tabs carry `data-active`. Count saves by wrapping `IDBObjectStore.prototype.put` in an init script and filtering key `document`; the saved shape is `document.animation` in the `keyval-store` database.

Source: `components/Animation/` (`AnimatePanel.tsx`, `TransportBar.tsx`, `StripTimeline.tsx`, `createSegmentResize.ts`, `SegmentDetails.tsx`, `PhoneSteps.tsx`, `timelineGeometry.ts`, `EasingField.tsx`, `EasingCurve.tsx`, `HeaderField.tsx`, `StepsMenu.tsx`, `AnimationPreview.tsx`, `PreviewPill.tsx`, `planPreview.tsx`, `createPreviewSnapshot.ts`), `state/editor/animation.ts`, `state/editor/animationSettings.ts`, `core/animation/easing.ts`, `core/animation/timeline.ts`, `components/Animation/AnimateToggle.tsx`, `pages/UnifiedEditor/controls/CanvasToolbar.tsx` (desktop toggle under the canvas), `pages/UnifiedEditor/stage.tsx`, `pages/UnifiedEditor/variants/*/index.tsx`, `i18n/animation.ts`.

## Gotchas

Drive it through the controls. `scripts/parity/live-animate.ts` seeds fixtures through the store. Its regression lanes use the visible controls for step removal, playback and commands, keyboard details, custom easing commits, and long-strip scrolling. Older Header/Pill/Scrub cases still seek through the store; audit covers opening and playback from the user entry points.

A click that succeeds does not prove a control is visible. Playwright scrolls `overflow: hidden` boxes, and the kit popover clips its content, so compare each control's box with the dialog's box and the viewport, and hit-test their centers and edges before clicking them. The Easing lane checks the curve, Custom field, validation message and Play transition. Check that the curve, the Custom field and Play transition sit inside dialog `Easing` in every layout and at 390×844.

Assert displayed values, not only stored ones: after selecting a segment, `#animationDuration-input` must show its duration, including the literal `0` for a zero-duration hold before focus and after blur. Type into it with the keyboard and commit with Enter or Tab. The duration uses a string-valued kit TextField so zero remains visible, with stable kit step buttons. Enter preserves focus. The field commits on Enter, blur, Arrow Up/Down and the duration steppers. Escape reverts its pending value and retains the selection and input focus. The steppers are pointer controls; Arrow Up/Down provide the keyboard path, and Tab skips the step buttons. Custom easing also commits on blur; entering a preset’s points keeps the Custom field mounted. A custom curve's y values are stored clamped to 0..1, and an x outside 0..1 shows `Use four numbers with x between 0 and 1.` and saves nothing.

Steps join only on the first open. A tab added later needs Steps → Add to animation. With nothing selected, Duplicate, Move and Remove are disabled. A menu takes up to 0.8 s to leave the page after it closes, so wait for `[role=menu]` to detach before the next action. New tabs use UUIDs with the `$0` version suffix. The duplicate-focus audit checks distinct saved tab IDs and the copied code. Duplicate as next step returns focus to the new tab's code after the menu's focus restoration; other menu actions return to Steps. Closing a tab removes its steps, and with one step left `Play animation` is disabled. Preview planning pairs settings with their matching measurement snapshot; timing-only edits reuse the measurement. RemoveDuringPreview removes each of three steps while paused and playing, checks menu closure and the remaining strip, and waits for IndexedDB to contain the removal. Fail on any `pageerror` or nonexistent-droppable warning.

Typed keys reach the code only while the preview stage holds focus. Play, Play transition and the playback command move focus to the stage, so printable keys edit the current step and bypass app hotkeys. PlayFocus checks both the Play button and command menu. Clicking the stage focuses it; only the pill, Enter, Esc or a printable key returns to the code.

In the default macOS window the add button has no accessible name and every `[data-host-index]` tab exists twice (canvas and export copy). A save is debounced: wait for the write before reloading. The What's new nudge of a first visit covers the toggle's left edge in Inspector desktop and Dock phone. The strip has one tab stop. Up/Down, Home/End move selection; Left/Right nudge its duration (Alt uses 10 ms). Tab reaches that segment’s duration, then Easing and Apply to all. Tab from the duration reaches Easing directly, and Shift+Tab returns to the duration. Apply to all retains focus when every transition matches, announces `aria-disabled`, and ignores further activations. The desktop strip and phone overview use `timelineGeometry(segments, width, {labels, minWidth})`. The returned entries contain each segment, x, width and label mode. Tick records include their time, position and alignment; a lone zero tick is start-aligned. Gaps contract before editable slots shrink below 8 px. If the available strip cannot fit 8 px per segment, the panel reuses the overview, step list and sheet, including on desktop. Number labels reserve padding and disappear when they do not fit. The same table maps ruler ticks, playhead, pointer scrubbing and resize conversion. Its tick generator keeps labels at least 64 px apart even when reserved segment widths make the time axis uneven. Gaps are at most 3 px. The density fallback avoids overlapping targets or horizontal scrolling. Zero holds retain a selectable slot, and time zero stays at x=0 even when the first hold is zero. The strip is hidden until synchronously measured on mount, so its first visible frame already fits. The desktop strip always fits: hold labels collapse to numbers, and narrow transitions lose their label. Resize conversion captures the pointer-down geometry while the displayed strip refits during the drag. There is no horizontal scrolling or playback following. The panel uses a bounded grid (60dvh, with a 300 px floor for landscape). Strip mode scrolls its timeline and segment fields below the transport. List mode scrolls only native step rows. Both menu triggers (Steps and Add step), the transport and the header select stay outside scrolling containers. This avoids Kobalte’s scroll-parent loop when keyboard opening a menu on a page with scroll locking. The compact footer groups the header and Add step controls so both remain reachable in short windows.

Phones use the unified editor's `compact` breakpoint. `[data-animation-scroller][data-overview]` is a 40 px scrub target with a thin, unlabelled strip. `[data-overview-segment]` exposes its geometry. Dragging previews the time under the pointer; releasing selects the destination step without opening its sheet. `[data-animation-step-list]` is an ordered list with `[data-animation-step-row]` buttons identified by `data-step-id`. Each row shows the tab, incoming transition with an easing glyph, and hold. The footer’s `[data-animation-add-step]` button opens the tab picker, so existing tabs can be reused beyond the six-tab limit. The list scrolls vertically at roughly 200 px tall.

Tapping a row opens `[data-animation-step-sheet]`, a modal dialog bound to the selected step id. `#animationHold-input` and `#animationTransition-input` reuse DurationInput. The first step has no incoming transition. Easing and Apply to all use the existing controls and actions. Move, duplicate and remove live in the sheet. Its duration steppers sit beside the input rather than covering its text area, and have separate hold/transition names. Row buttons own a single accessible name; the first explicitly announces no incoming transition. At the six-tab limit, Duplicate has a visible description explaining that a tab must be closed. The desktop menu keeps it arrow-key reachable with `aria-disabled` and a description inside the item; activation leaves the tabs unchanged. Moving a step to either end transfers focus to the other Move button before the initiating control becomes unusable. Its controls are at least 40 px; focus is trapped and restored to the triggering row on close, or the first remaining row after removal. Escape closes the sheet. Inside a duration field, the first Escape reverts the pending value and the second closes. Editing resets that sequence. The sheet moves focus to its Close button a few milliseconds after it appears, and the row gets focus back a few milliseconds after the sheet is removed. Wait for focus inside the sheet before typing, or the late focus move blurs the field and commits the typed value; poll for the row's focus after closing.

Controls checks 40 px tall phone buttons and Settings segmented-control Escape behavior; the Settings dialog can be an `alertdialog`, so match both dialog roles. The Animate command focuses its panel or toggle. The app theme follows `localStorage` `@store/ui` (`themeMode`), not the browser's colour scheme, so set it there for light-theme proof. Audit `animate` covers opening, playback, the pill and resize persistence in Inspector desktop. `animate-focus` and `animate-geometry` cover desktop regressions in all three layouts at 1440×900; `animate-phone` covers 390×844. Easing presets, custom curves and header modes still need their specialist lanes.

## MP4 export

After two steps are saved, Export video and its arrow open MP4 settings while Animate is open. Export as image returns to the image controls. The dialog owns the 24/30/50/60 fps choice and persists it in the animation settings, so reopening the dialog and later exports use the same rate. The Animate panel still has no fps field. Export measures the same static step layouts and uses planPreviewTimeline, frameRules and the same header/timing/easing settings as this preview. A pure core/animation/target-layout.ts helper places windows in social targets.

The five `animation-mp4` audit cases cover layouts, failures, compositing, export modes and static-frame parity; see [Export](export.md) for controls, worker cancellation, unsupported configurations and remaining platform checks.

## GIF export

Animate's export menu now chooses MP4 or GIF in the same settings. MP4 remains the initial format; GIF defaults to 25 fps and supports 50 fps, with an explicit note when a 60 fps choice plays at 50. The export-only 25 fps value does not change the persisted animation schema. GIF uses the same measured timeline and raw RGBA job as MP4. `animation-gif` and `animation-gif-fallback` cover downloads in all layouts, the fps note, size suggestion, cancel, MP4 fallback and decoded frame fidelity; the five MP4 cases and baseline PNG retain regression coverage. See [Export](export.md) for decoder tolerances and replay commands.
